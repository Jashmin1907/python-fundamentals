# Python Fundamentals — Code Examples

This folder contains runnable examples for the Python teaching guide.

## Requirements
- Python 3.10+ recommended
- No third-party packages are required for the examples.

## Run an example
Open a terminal in this folder and run, for example:

```bash
python 01_hello_world.py
```

Some examples ask for input. Follow the prompts in the terminal.
